# YAPPER — V0.2 Roadmap (Gamer-Centric Feature Expansion)

> Created: 2026-03-05
> Status: Draft — Pending approval before sprint planning
> Prerequisite: V0.1 MVP launch complete (S11 W24 checklist ✅)
> Philosophy: Free-first, community-driven, no Discord paywall patterns

---

## Overview

V0.2 targets the **gamer audience** as Yapper's primary growth vector. The features below are
grouped into 4 sprints (G1–G4) and directly address the top frustrations with Discord:
performance paywalls, no native game integration, generic social UX that ignores gaming context.

**V0.2 does not break E2EE.** All game metadata, presence, and social features operate on
public/shared data only. No message content is accessed or exposed.

## G1 — Game Presence + Core Gamification (Weeks 1–2)

**Goal:** Users see real game status, earn XP, and servers react to emoji automatically.
**No new infra costs.** All game data is user-provided via connected account APIs.

## Deferred to V0.3

The following were brainstormed but are too complex or too risky for V0.2:

| Feature | Reason for Deferral |
|---------|---------------------|
| Match history auto-feed (Steam/Riot) | Requires reliable API polling + per-game parsing — high maintenance surface |
| Clip preview GIF generation | canvas-to-GIF is expensive; JPEG thumbnail from single frame is G4's simpler alternative |
| Full whisper.wasm integration | 150MB model; G4 uses `webkitSpeechRecognition` first with whisper as fallback |
| Cross-server leaderboard | Data privacy concerns — users may not want global ranking without opt-in |
| AI-powered moderation heuristics | Out of scope until user base justifies cost |
